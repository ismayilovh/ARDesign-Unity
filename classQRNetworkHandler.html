Detailed Description

Singleton that downloads a glTF/GLB model from the URL encoded in the scanned QR code and loads it into the scene using GLTFast.

Shows a progress-bar popup during download and an error popup on failure. On success it sets DesignManager.Design and transitions to StateMachine.States.MODEL_VIEW_STATE.
