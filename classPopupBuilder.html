Detailed Description

Fluent builder for creating PopupWindow instances.

Instantiates the Popup Window prefab from Resources, attaches it to the PopupParent tagged object, and configures it via chained method calls.

GameObject popup = PopupBuilder.Create()
.WithHeader("WARNING")
.WithContentText("Are you sure?")
.WithFooterButton("OK", PopupWindow.BUTTON_COLOR_OK, OnOK)
.Get();
