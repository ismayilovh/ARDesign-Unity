Detailed Description

Owns the reversible pivot offset for a spawned design and also provides the bounds and positioning helpers used when placing or scaling a design in AR.

Repositions design so its bounding box no longer overlaps the camera position in the XZ plane, pushing it along the camera's forward direction when the camera is inside the model bounds.

Used when switching to 1:1 real-world scale mode.

Parameters
designThe root GameObject of the design model.
camTransformThe AR camera transform.
offSetExtra clearance distance in metres beyond the model edge.
Returns
The calculated offset vector (currently always Vector3.zero), or Vector3.positiveInfinity if design is null.

static void PivotSetter.SnapToYOffset ( GameObject  design,
bool  toGround,
bool  usePivot 
)
static

Adjusts the Y position of design so its bottom face sits on the detected AR plane (when toGround is true) or its center aligns with the spawn Y coordinate.

Also re-centres the XZ pivot relative to the bounds center.

Parameters
designThe root GameObject to reposition.
toGroundtrue to snap the bottom of the model to the plane surface; false to align the center.
usePivottrue to treat the transform position as the pivot point; false to use the bounds center.
