Detailed Description

Singleton that downloads a glTF/GLB model from the URL encoded in the scanned QR code and loads it into the scene using GLTFast.

Shows a progress-bar popup during download and an error popup on failure. On success it sets PatentManager.Patent and transitions to StateMachine.States.MODEL_VIEW_STATE.

Stops all download coroutines, returns to StateMachine.States.NO_MODEL_VIEW_STATE, and destroys the download popup.

The popup is destroyed (not hidden) because either a progress or error variant may exist.
