Detailed Description

Static utility class providing pivot calculation, bounds computation, and model-positioning helpers used when placing or scaling a patent in AR.

Vector3 PivotSetter.ChangeToOneOneMode ( GameObject patent,
Transform camTransform,
float offSet )
static

Repositions patent so its bounding box no longer overlaps the camera position in the XZ plane, pushing it along the camera's forward direction when the camera is inside the model bounds.

Used when switching to 1:1 real-world scale mode.

Parameters
patentThe root GameObject of the patent model.
camTransformThe AR camera transform.
offSetExtra clearance distance in metres beyond the model edge.
Returns
The calculated offset vector (currently always Vector3.zero), or Vector3.positiveInfinity if patent is null.

Bounds PivotSetter.GetBounds ( GameObject patent)
static

Computes the local-space axis-aligned bounding box of patent by transforming all mesh-corner vertices into the root object's local space.

More accurate than GetSpawnBounds for rotated hierarchies.

Parameters
patentThe root GameObject whose mesh filters are measured.
Returns
The local-space Bounds, or a small default if no meshes exist.

◆ SnapToYOffset()

void PivotSetter.SnapToYOffset ( GameObject patent,
bool toGround,
bool usePivot )
static

Adjusts the Y position of patent so its bottom face sits on the detected AR plane (when toGround is true) or its center aligns with the spawn Y coordinate.

Also re-centres the XZ pivot relative to the bounds center.

Parameters
patentThe root GameObject to reposition.
toGroundtrue to snap the bottom of the model to the plane surface; false to align the center.
usePivottrue to treat the transform position as the pivot point; false to use the bounds center.
