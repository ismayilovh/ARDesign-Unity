Detailed Description

Singleton component that samples the AR camera's CPU luminance plane every N frames and decodes it as a QR code using the ZXing library.

When a code is found the state machine transitions to StateMachine.States.QR_SCAN_COMPLETE_STATE and the decoded URL is available via QrCode.
