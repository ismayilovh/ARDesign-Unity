Detailed Description

MonoBehaviour that automatically generates two LOD levels for its GameObject using UnityMeshSimplifier's LODGenerator on Awake.

LOD 0 keeps full-quality geometry; LOD 1 uses 65 % mesh quality with combined meshes for better performance. The last LOD is culled by default. Added dynamically to downloaded patent models by QRNetworkHandler.
