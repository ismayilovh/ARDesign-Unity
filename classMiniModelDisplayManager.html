Detailed Description

Renders a miniature preview of the loaded patent model into a RenderTexture and displays the result in the UI as a Sprite.

Triggered when entering StateMachine.States.MODEL_VIEW_STATE and reset on QR scan. Requires a Camera component inside the loaded model's hierarchy.
