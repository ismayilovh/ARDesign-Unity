Detailed Description

Singleton utility that calculates the uniform scale factor needed to fit a patent model within a configurable fraction of the device screen.

Uses the camera's FOV and the model's world-space bounds from PivotSetter.GetSpawnBounds.

Parameters

usePivotWhen true, uses the object's transform position as the reference center; otherwise uses the bounds center.
Returns
The scale multiplier to apply, or -1 if the calculation cannot proceed (null inputs or screen fit disabled).
