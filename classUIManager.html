Detailed Description

Legacy coordinator for the older UI layer.

Bridges PlaneDetectionController toggles and ResetDesignButton clicks to RaycastHandler, ScreenScaler, and ObjectSpawnerAR. Superseded by the New UI system in Scripts/UI/New UI/.
