Detailed Description

Manages the Add Model button that allows the user to scan a new QR code.

The button toggles between an "add" icon (shows a confirmation popup) and a "cancel" icon (cancels an in-progress QR scan). Reacts to StateMachine state changes to keep its state consistent.
